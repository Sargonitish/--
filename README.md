## 🛠️ Tech Stack
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 & custom CSS
- **Animations**: GSAP (ScrollTrigger, SplitText, DrawSVG, CustomEase)
- **Smooth Scroll**: Lenis
- **AI Assistant**: Custom-built `askNitish` chat assistant with OpenRouter backend

## 🏃 Getting Started

### Prerequisites
- Node.js 20+ installed

### Development Server
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

### Production Build
```bash
npm run build
npm run start
```
